# Интерактивный прототип приложения

Интерактивная демонстрация, перенесённая из Google Презентаций.

- Переходы выполняются только через настроенные активные области.
- Клики по фону и клавиши перелистывания не меняют экран.
- Данные прототипа: 62 экрана, 150 активных областей.

Публичная версия: https://daryaguseva111.github.io/app-demo/
